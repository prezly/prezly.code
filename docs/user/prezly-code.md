# Create a project in Prezly.code

Choose **Create project** from the new-prompt project picker, the empty project screen, or the
command palette. Select the repository, branch, GitHub identity, and model for the new Jude
environment. Prezly projects can also include optional custom license IDs.

Prezly.code keeps the creation dialog open while Jude provisions the environment. When it is ready,
the project connects automatically and appears in the new-prompt project picker. If provisioning
fails or takes longer than 15 minutes, the dialog reports the failure; the environment can still be
picked up later with **Refresh Jude environments**.
